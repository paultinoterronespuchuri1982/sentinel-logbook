# sentinel-log

Sentinel Log: electronic logbook and SOLAS/IMO compliance report generator using Claude API

A FastAPI backend that turns FPSO (Floating Production Storage Offloading) watch
logs into structured SOLAS/IMO compliance reports using Claude, with a simple
web UI for entering logs and viewing generated reports.

## Setup

```bash
pip install -r requirements.txt
cp .env.example .env   # then set ANTHROPIC_API_KEY
python main.py
```

The app runs at http://localhost:8000.

> **Draft only.** Reports are generated by a language model and are drafts.
> They do not replace review and sign-off by the responsible officer, and
> they are not an official SOLAS/IMO document.

## Tests

```bash
pip install -r requirements-dev.txt
pytest
```

The tests do not call the Anthropic API and do not need a database. The
Claude client is replaced with a fake in the tests that need a model reply.

## Design decisions

- **Local bind by default.** The server listens on `127.0.0.1`. `HOST=0.0.0.0`
  is only for use behind an authenticated proxy, because the API has no
  authentication of its own.
- **Restricted CORS.** Only origins in `ALLOWED_ORIGINS` can call the API from
  a browser. Credentials are off and wildcard origins are not used.
- **Secrets stay in the environment.** The key is read from `.env`, which is
  git-ignored. `.env.example` holds placeholders only. `/health` reports
  whether the key is set, not whether it is valid.
- **Each report is independent.** No conversation history is kept, so one
  watch record cannot leak into another report.
- **Bounded replies.** `max_tokens` caps the length of the model reply.
- **Output is never lost.** If the model does not return valid JSON, the raw
  text is placed in `executive_summary` and the other sections are marked
  "See summary".
- **Errors are logged, not echoed.** Full exceptions are written to the server
  log. The client only receives a generic message, so internal details and
  credential fragments are not exposed.
- **Speech stays on the machine.** Voice transcription uses faster-whisper
  locally. Audio is not sent to any service. Without it, the page falls back
  to the browser's built-in dictation.

## API

- `GET /health` — service/health check
- `POST /api/sample-logs` — returns a sample operational log payload
- `POST /api/generate-report` — generates a compliance report from an
  `OperationalLog` (see `main.py` for the schema), with `language` set to
  `en` or `pt`

## Voice dictation with a local model (optional)

The page can transcribe speech on your own computer with faster-whisper.
No account or payment is needed. The first use downloads the model once.

```bash
python3 -m pip install -r requirements-voice.txt
python3 main.py
```

- `WHISPER_MODEL` chooses the model: `base` (about 150 MB, faster) or `small` (about 500 MB, more accurate). Default: `small`.
- If the model is not installed, the microphone uses the browser's built-in dictation instead.
- Audio is processed on this computer and is not sent to any service.
